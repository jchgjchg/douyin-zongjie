# 一句话核心
1993年，澳门文华东方酒店门口，陈耀兴遭伏击身亡，揭开了一段因卡拉OK包厢耳光引发的跨海追杀和江湖恩怨。

## 内容结构与要点
1. **背景介绍**：1993年11月21日，澳门文华东方酒店门口发生了一起枪击事件，陈耀兴当场身亡。陈耀兴是香港新义安帮派的湾仔之虎，拥有极高威望。
2. **事件起因**：事件的导火索是一年前，歌星梅艳芳在九龙塘卡拉OK包厢被14K帮派大佬黄朗维耳光扇脸。梅艳芳向陈耀兴求助，陈耀兴派人报复黄朗维，黄朗维在医院被杀。
3. **报复与追杀**：黄朗维的拜把兄弟黄朗辉誓言要为兄弟报仇。陈耀兴在澳门参加赛车时，黄朗辉雇佣杀手将其击毙，并留下“下一个是梅艳芳”的威胁。
4. **影响与后续**：陈耀兴的死引发了香港黑道的震动，他的故事被搬上大银幕，《醉生梦死之湾仔之虎》和《古惑仔》系列电影使他的形象深入人心。

## 关键概念/模型解析
- **帮派文化与利益冲突**：香港90年代黑帮文化中，帮派间的利益冲突和地盘争夺是常有的事。陈耀兴的崛起和最终的覆灭正是这种文化的体现。
- **黑帮电影的影响**：电影《古惑仔》系列使陈耀兴的形象被刻画成“陈浩南”的原型，影响了一代年轻人对黑帮文化的误解。
