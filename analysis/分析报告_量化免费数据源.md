## 核心内容

### 一、为什么免费数据够用（破误区）
- 误区：没几万块终端（Bloomberg/Wind）就做不了量化。作者自述被这想法耽误大半年。
- 机构要的：逐笔数据、毫秒级、十档盘口、卫星图像（高频/微观结构/另类因子）——那是机构的战场。
- 你要的：**日K线**（中低频）、**财务数据**（基本面）、**宏观数据**（大环境）、偶尔分钟K线（日内验证）。量级完全不同。
- 比喻：学开车不需要全新跑车，需要能开的教练车；免费数据=教练车，策略验证成功再换"跑车"不迟。
- **免费 vs 付费真实四点差距**：
  1. 数据频率：免费日频/分钟频，付费逐笔级 → 日频做中低频绰绰有余
  2. 数据延迟：免费 T+1/15 分钟，付费实时 → 日频策略延迟一天不重要
  3. 数据质量：免费偶有错缺需自清，付费专业处理 → 但付费你也得做基本检查，没人兜底
  4. 稳定性：免费可能宕机/限流，付费有保障 → 有备用源即可解决
- 结论：这四点对中低频策略几乎可忽略。机构花大钱因高频每毫秒是钱、管几十上百亿边际收益高；你一年交易几十次、持仓几周几月，要的是日K线不是逐笔。

### 三、搭建数据获取系统（五步）
1. **定需求**：问三问——做哪市场（A股/美股）？要什么频率（日/分钟）？要什么类型（价格/财务/宏观）？
2. **主+备双保险架构**：不依赖单一源。写函数先试主力，失败自动切备用（如 Tushare 挂了自动从 BaoStock 拉）。代码不复杂但能救很多次。
3. **本地缓存**：首次拉取存本地，下次先查缓存；设更新时间（如每日收盘后更一次）。大部分时间读本地，快且稳不依赖网络。
4. **质量检查（每次用前跑）**：免费数据非完美，可能有缺失/异常/日期不对齐。检查三件事：① 缺失值及比例（超 5% 停查）② 异常值（如某天股价变 0）③ 日期是否连续（漏交易日）。作者吃过亏：一次回测某股成交量连续三天为 0（非停牌，是源出错），没检查就当真数据算，整个回测废了。
5. **知边界**：高频/逐笔、分钟级日内实时、冷门另类（社媒情绪/卫星）才需付费——那是进阶阶段。判断标准：**持仓周期 >1 天 → 免费够；<几小时 → 考虑付费；要逐笔精度 → 必付费**（那时你应有收入覆盖成本）。

### 四、收尾（价值观）
1996 雅虎把数据免费开放，"免费数据能有什么用"的人错了——30 年后全球最大个人投资者社区就建在其上。数据价值不在多贵，在谁用、怎么用。免费数据给了零成本起点，门槛是思维不是数据，愿不愿意现在迈第一步。
