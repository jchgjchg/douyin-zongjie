# 短视频内容分析报告

## 一句话核心
AI agent高效使用的关键在于明确工作边界。

## 内容结构与要点

1. **引言与背景**
   - 视频作者通过烧掉大量token的经验，总结出AI agent的高效使用方法。
   - 两个常驻skill解决了不同问题，但核心在于明确agent的工作边界。

2. **项目文件夹的重要性**
   - 项目文件夹帮助沉淀项目经验和固定工作环境。
   - 类比于办公室，项目文件夹提供了固定的规则和工具，便于新对话快速上手。

3. **对话管理**
   - 对话管理类似于工单，不同任务应分开聊，避免上下文过长导致任务出错。
   - 交接skill帮助及时提醒换对话，并整理交接内容，避免重复工作。

4. **子agent的应用**
   - 子agent的核心价值在于上下文隔离，避免烧掉过多token。
   - 网页替身skill利用ChatGPT网页端和Codex端的分离，自动化分流重度分析任务。

5. **worktree的使用**
   - worktree为每个对话单独复制项目，避免互相覆盖和干扰。
   - 适用于多发案并行时，独立跑动后再合并最佳结果。

6. **总结与建议**
   - 明确agent的工作边界，避免把所有任务都塞进同一个地方。
   - 通过项目文件夹、对话管理、子agent和worktree，提高AI agent的使用效率。

## 关键概念/模型解析

- **token**：在自然语言处理中，token是指单词或词组，AI模型通过处理token来理解和生成文本。
- **agent**：AI agent是指具有一定智能和自主性的软件程序，能够根据指令执行任务。
- **上下文隔离**：通过将不同任务的上下文隔离开来，避免信息混淆和资源浪费。
- **worktree**：类似于版本控制中的分支，为每个对话单独复制项目，避免互相干扰。

- **可信度评估**：作者通过实际经验总结出的方法，具有较高的可信度，适用于AI agent的高效使用。

## 实战建议

1. **建立项目文件夹**：
   - 为每个长期项目建立独立的项目文件夹，沉淀项目经验和固定工作环境。
   - 确保新对话能够快速上手，避免重复工作。

2. **合理管理对话**：
   - 定期检查对话长度，及时进行交接，避免上下文过长导致任务出错。
   - 使用交接skill提醒换对话，整理交接内容，提高工作效率。

3. **利用子agent和worktree**：
   - 为重度分析任务使用子agent或网页替身skill，避免烧掉过多token。
   - 在多发案并行时，使用worktree为每个对话单独复制项目，避免互相干扰。
