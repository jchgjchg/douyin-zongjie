## 一句话总结

已经有服务器和域名后，新做的 Vibe Coding HTML 作品**不需要每次重新买服务器、注册新域名**——一台服务器可以放多个站点，一个主域名可以拆出多个子域名，每个子域名分别绑定一个站点，后续部署都是「重复第一次的动作」。

---

## 核心原理（记住这三点，整期就通了）

作者先用一分钟讲原理，再实操。三条心智模型：

1. **一台服务器可以放多个站点**：同一台服务器里可以建多个网站目录，第一个文件夹放个人主页、第二个放小工具、第三个放博客，彼此独立。
2. **一个域名可以创建多个子域名**：我们常见的 `www` 其实是可以自定义的——所以可以有 `www`、可以有 `tool`、可以有 `blog`，甚至直接用你的项目名称当子域名。本质是「一个主域名 = 多个入口」。
3. **不同的子域名分别绑定不同的站点**：`www` 指向第一个站点、`tool` 指向第二个、`blog` 指向第三个。

> 关键认知：**`www` 不是必须的，是可自定义的**。很多人第一次意识到「原来 www 只是默认子域名之一」。

## 实操步骤（以可视化面板 / 宝塔类面板为例）

本期的目标是：在「上期已部署的个人主页（www）」所在的那台服务器上，再增加 `tool`（工具）和 `blog`（博客）两个作品，三者共用同一台服务器、同一个主域名。

### 步骤一：添加站点
- 打开服务器可视化面板，进入站点管理，选择「添加站点」。
- 域名填**子域名**，例如 `tool.你的主域名.com`（第一次加主站时填的是主域名/IP，这次填二级域名）。
- 备注：写「我的工具」。
- 数据库：**不创建**。
- 运行环境版本：选「**纯静态**」（因为是纯 HTML 静态页面，无需 PHP/数据库）。
- 确定，站点创建完成。

### 步骤二：上传文件到根目录
- 进入该站点的根目录，把本地准备好的 HTML 小项目直接**拖拽上传**（覆盖式上传即可）。
- 例：`tool` 站点放的是一个「视频口播次数与时长的计算器」小工具；`blog` 站点放的是一个简单个人博客。

### 步骤三：域名解析（A 记录）
- 到域名解析后台，「添加记录」。
- 类型：**A 记录**。
- 名称（主机记录）：填子域名前缀 `tool`（注意：主站当时填的是 `www`，这里换成 `tool`）。
- 记录值：填**服务器的公网 IP**，保存。
- 解析生效后再到面板站点设置里配置 SSL。

### 步骤四：配置 HTTPS（免费证书）
- 进入站点「设置」→「SSL」→ 申请**免费证书**，选择对应子域名，稍等申请成功。
- 开启「**强制 HTTPS**」并保存，避免裸 http 访问。

### 步骤五：重复部署第二个站点（blog）
- 回到面板「添加站点」，域名填 `blog.你的主域名.com`，备注「我的博客」，不创建数据库，版本选纯静态，确定。
- 进根目录上传博客文件（拖拽覆盖默认首页），保存。
- 域名解析：再加一条 A 记录，名称 `blog`，值=服务器 IP，保存。
- SSL：站点设置 → 免费证书 → 申请 `blog` → 开启强制 HTTPS。

## 最终效果

| 子域名 | 站点内容 | 服务器 | 主域名 |
|---|---|---|---|
| `www.主域名.com` | 个人主页 | 同一台 | 同一个 |
| `tool.主域名.com` | 小工具（口播计算器） | 同一台 | 同一个 |
| `blog.主域名.com` | 个人博客 | 同一台 | 同一个 |

三个地址、三个网站，背后就是**同一台服务器 + 同一个域名**。

---

## 关键结论 & 可复用心法

- **第一次部署最难，后面全是重复**：第一个站点（www）跑通后，tool、blog、以及你未来任何新做的 Vibe Coding 页面，流程完全一致——添加站点 → 上传 → A 记录解析 → 申请 SSL → 强制 HTTPS。
- **成本心智**：不要陷入「每做一个网页就买一台服务器、注册一个域名」的误区；多站点 + 多子域名是标准做法。
- **练手建议**（作者原话）：找一个你之前做过的页面，再给自己加一个子域名跑一遍，就能彻底掌握。
