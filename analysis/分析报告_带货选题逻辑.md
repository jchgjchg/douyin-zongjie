## 一句话核心
带货视频能不能爆，**产品只决定后半场（退货/复购），选题决定有没有上半场（用户点不点得进来、停不下来）**；作者把选题拆成三层校验标准——**停留、破圈、下单**，先对选题再写脚本，多数低播放的锅不在文案表达，在选题层。

---

## 核心内容：选题三层框架

### 第〇层：总论（产品 vs 选题）
- "我写了三年带货脚本、废过一百多条、也爆过近百条"——经验口径下，出单与否：**产品是答案，选题是问题；没有问题的答案，没人听**。
- 用户刷视频**不是在找产品，是在找自己**。开头给参数→脑子没缺口；开头给处境→脑子马上有画面，这画面就是停留理由。

### 第一层 · 停留（选题决定用户为什么停）
- 真正出单的挂车视频，开头**不是产品，是一个正在发生的生活切片**：
  - 坐垫 → "你不是坐不住，是腰在替你加班"
  - 除螨仪 → "你每天早上打喷嚏，可能不是感冒，是床在养东西"
  - 保温杯 → "你不是不爱喝水，是水凉了以后你就不想碰"
- **选题 ≠ 标题**：标题是包装，选题是内容本身，要制造一个**悬念缺口**——用户有个问题，答案不在开头，你留一个"为什么"，他才等一个"所以"。问题开头就种下，价格/结果留最后；观众带着问题看到底，购物车一点、答案才出来。
- 写法：写脚本前先写**用户会说的三句话**（不是产品的三个卖点），挑最具体的一句当开头。
- 金句：**钩子只是选题的外化。选题不对，钩子再花也是标题党；选题对了，钩子就是把用户正在想的那句话说出来。**

### 第二层 · 破圈（选题决定谁愿意看下去）
- 反"死垂直"：卖母婴就只拍母婴、卖宠物就只拍宠物，爆款不是从品类里讲出来的，**是从人的共同处境里讲出来的**。
  - 护眼灯 → 不急讲护眼，讲"为什么孩子一写作业就揉眼睛"（看的人不止宝妈，还有所有小时候在昏灯下写过作业的人）
  - 猫用品 → 不急讲去浮毛，讲"猫掉毛最严重不是换季，是你回家太晚它焦虑"（不养猫也懂焦虑）
  - 防滑拖鞋 → "爸妈不是不怕摔，是怕给你添麻烦"（破圈到所有有父母的人）
- **功能 → 场景 → 母题** 跳三层：
  - 护眼灯：功能=护眼 / 场景=写作业揉眼睛 / **母题=怕孩子吃苦**
  - 猫用品：功能=对付掉毛 / 场景=回家太晚猫焦虑 / **母题=怕被依赖的人失望**
  - 防滑拖鞋：功能=防滑 / 场景=爸妈怕摔 / **母题=怕父母变老、怕自己来不及**
- 结论：**母题越大，流量池越大**。"不要问我这个品类能拍什么，要问这个产品能替什么人群说出什么共同处境。" 品类决定你卖给谁，选题决定谁愿意看——垂直是结果，破圈是选题的因。

### 第三层 · 下单（选题决定用户为什么现在买）
- 讲卖点→用户防御；讲他正在经历的选题→他自己找理由。
  - 毛球修剪器：不讲功率，问"你有没有过这种时候：大衣起了球，舍不得扔，穿出去又浑身不自在"
  - 收纳箱：不讲容量，讲"家里那些杂物总得有个地方临时放一下，不然永远收拾不干净"
  - 洗碗手套：不讲家务，讲"冬天洗完那个瞬间，水一凉、手还油，你连碗都不想碰了"
- 用户下单前需要三样：**场景紧迫感 + 身份认同 + 结果想象**，选题同时给三个（起球见人=紧迫感；"我也有这件大衣"=身份认同；"不再尴尬"=结果想象）。卖点只给参数，选题给的是**生活后果**。
- 翻译公式：把卖点翻译成生活后果——
  - 续航30天 → "出差一周不用带充电器，也不用求人借"
  - 大容量 → "一家三口周末采购不用分两趟拎"
  - 防水 → "下雨天接孩子，书包里作业本还是干的"
- 收尾：产品出现时不是介绍，是**修为（收尾/递货）**——用户理由已自己找完，你只把货递过去。**卖点解决"它有什么"，选题解决"我为什么现在要买"；用户不会为参数冲动，会为一个被说中的自己冲动。**

### 总收
产品决定退货和复购，但用户**能不能刷到你、愿不愿意点进来，是选题的事**。包装改800遍、成分写再清、价格压再低，不如先想明白：这产品该放进**谁的故事里**。**题对了，产品是答案；题错了，产品是噪音——别让好货输在第一道题上。**

## 可信度分层

| 内容 | 可信度 | 说明 |
|---|---|---|
| 产品=答案/选题=问题；用户"找自己不是找产品" | **高** | 带货文案经典法则（问题前置/痛点开场），平台机制成立 |
| 三层框架（停留/破圈/下单）+ 母题越大流量越大 | **高** | 功能→场景→母题的升维法、破圈靠共鸣而非品类，均为成熟电商内容方法论 |
| 下单三要素（紧迫感/身份/结果想象）+ 卖点译生活后果 | **高** | 行为经济学+场景化文案，实操性强 |
| "写了三年、爆过近百条"经验背书 | **中** | 自述、不可独立验证，但表述专业、内容质量佐证其为 practitioner |
| 标题"产品不重要，选题才重要"（绝对化） | **中（标题党）** | 正文已自纠：产品决定退货复购、选题决定前半场——绝对句是钩子，实际持平衡论 |

**整体立场**：本片是 68 条里**结构最硬、可直接照搬**的电商带货教程之一，三层框架即"选题校验清单"，落地性强。唯一要注意的是标题的绝对化是为了完播钩子，正文已做平衡，理性吸收即可。
