## 一句话核心
不管 Agent 产品怎么换名字、怎么包装，底层全是**同一个公式**：大模型只有 3 个死板的信息通道（System Prompt / User Prompt / Tools），而 Agent 就是在大模型之上**玩出 6 种包装能力**（动态提示词 / 记忆 / 外挂知识库 / 任务推演循环 / 本地工具 / 外部服务）的应用程序——脑子装下这套"3+6"，再看任何新 Agent 都能一眼看穿它在玩什么。

## 核心内容（结构化）

### 一、先分清：大模型 ≠ Agent
- **大模型**（DeepSeek V4、Kimi K3 等）本质是一台"干巴、冷酷、甚至有点死板"的文本处理机器，认识世界只通过 **3 个死板通道**：
  1. **System Prompt（系统提示词）**：交代聊天背景，你是谁、遵守什么规范
  2. **User Prompt（用户提示词）**：你发给它的具体问题
  3. **Tools（工具）**：对大模型而言工具只是"信息列表"——它只知道有哪些工具可用、用了返回什么，至于工具怎么执行（读本地还是调接口）它完全不知道也不关心
- **Agent**（WorkBuddy、Codex 等）：架在大模型之上的**一套应用程序**。收你的问题 → 优化处理 → 整理成大模型能懂的 3 种信息交给大模型 → 把结果拆解后返回你。大模型只提供基础能力，Agent 负责把基础能力"包装成你身边的全能管家"。

### 二、Agent 的 6 种包装能力（"3+6"里的 6）
- **能力一 · 动态提示词优化**
  - 基础玩法：给大模型"掏人设"（问技术→扮架构师；问游戏→扮无敌玩家）
  - 进阶：复杂需求把几十上百条规则**固定到文本模板**，触发需求时读出来补进系统提示词——这种模板化技巧就是 **Skill**（视频称"强大又神秘的 Skill"）。
- **能力二 · 记忆优化**
  - 短期记忆：把当前窗口聊天记录全记下来，每次提问补进系统提示词
  - 长期记忆：跨窗口记住（如 WorkBuddy 记住"你是楼兰"，新任务不用再说也能用对应知识回答）
  - 隐藏硬核挑战：**上下文压缩**——聊一年记录太多大模型迟早撑不住；压缩策略好则"越聊越明白"，差则"聊着聊着大模型降智"。这是 Agent 厂商功力的分水岭。
- **能力三 · 外挂知识库（RAG）**
  - 大模型不懂你公司规定、不懂你本地私密文件（一问报销标准就抓瞎）
  - Agent 先去本地/公司知识库搜相关文档，悄悄塞进系统提示词当背景——这叫 **RAG（检索增强生成）**，让通用学霸变你身边百事通。
- **能力四 · 任务推演循环（最核心差异点）**
  - 现实提问很随意（"帮我搞定昨天的数据"大模型直接懵），好 Agent 不能把模糊问题直接扔给大模型
  - 三步：**问题改写**（昨天是哪天、数据是哪些）→ **任务拆解**（大目标拆小目标：找 Excel→清数据→画图表）→ **Agent Loop 循环**（先干啥后干啥；最厉害的是**允许犯错**——代码报错就把 error 日志抓回提示词，让大模型反思、自我纠错）
  - 不同产品 Agent Loop 套路不同，对任务适配度天差地别——这就是"这类任务用 A 更合适、那类用 B 更好"的根源。
- **能力五 · 本地工具调用**
  - 早期 Agent 只调通用函数（搜索、访问网页），离用户太远
  - 进化后把 Agent 部署在**用户电脑本地**，提前写好操作本地资源的函数（读写文件、执行 Python、控制鼠标键盘）——正因如此诞生了 **Codex、WorkBuddy** 这类强大本地 Agent，把大模型从"网上工具"变成"你身边员工"。
- **能力六 · 外部服务调用（MCP）**
  - 本地工具再强也访问不了企业庞大业务数据 → 诞生 **MCP（模型上下文协议）** 这个大杀器（调 GitHub 代码、Figma 前端设计、高德地图路线等都有成熟 MCP 服务）
  - 很多人以为 MCP 只是"连外部接口的工具"，其实协议内容远不止：把与大模型交互的重要信息统一打包——如定义 **Resource 资源接口**暴露内部数据格式、定义 **Prompt 提示词接口**让企业向客户暴露标准提示词。走传统 RPC 思路，但协议内容已按大模型方式彻底优化。

### 三、收尾升华
- Agent 走的还是老路子：以前围绕数据库/缓存/搜索引擎深挖产品需求，现在换成大模型三大基础能力深挖应用场景。
- **"Agent 基础能力 + 深挖外部需求 = AI 时代核心 = 你我努力的正确方向"**。

## 可信度评估（诚实标注）
- **框架可信度：高**。3（大模型 I/O 通道）+ 6（Agent 能力层）的划分与行业共识一致（提示词工程、记忆/上下文压缩、RAG、Agent Loop/ReAct、function calling、MCP 均为真实且主流的概念）；对 WorkBuddy/Codex/MCP/Skill 的描述与我们实际用法吻合。
