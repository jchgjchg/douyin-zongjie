## 三、内容拆解（按视频叙述顺序）

### 题目
> 当 x 无限趋近于 2 时，求 `(x³ − 8) / (x² − 4)` 的值。

### 解题主线（洛必达法则）

1. **代入观察（判定不定式）**
   - x→2：分子 `x³−8 → 8−8 = 0`；分母 `x²−4 → 4−4 = 0`。
   - 得到 **0/0 型不定式**——直接相除「说不清」，不能简单等于 0 或 1。

2. **反例铺垫（为什么不能直接比）**
   - 作者假设：若分母是 `x²−3`（→1），则分子→0、分母→1，极限明显 = 0。
   - 但本题分母是 `x²−4`，仍→0，两个无穷小「看谁更小」无法直观判断，必须上法则。

3. **洛必达法则**
   > 当分子、分母**同趋 0**（或同趋 ∞）时，极限 = **两者导数之比的极限**。
   - 分子导数：`(x³−8)' = 3x²`
   - 分母导数：`(x²−4)' = 2x`
   - 比值：`3x² / 2x = 3x / 2`

4. **再代入 x→2**
   - `3×2 / 2 = 3` → **答案 = 3**。

### 答案
**lim(x→2) (x³−8)/(x²−4) = 3**

## 四、知识点与易错点

| 项 | 说明 |
|---|---|
| 0/0 型 | 不能直接判为 0 或 1，是**不定式**，必须进一步化简（因式分解 / 洛必达）。 |
| 洛必达前提 | 分子分母**可导**且**同趋 0 或同趋 ∞**；满足条件才能「导数之比」。 |
| 备用解法（视频未提） | 因式分解也可做：`x³−8=(x−2)(x²+2x+4)`，`x²−4=(x−2)(x+2)`，约去 `(x−2)` 得 `(x²+2x+4)/(x+2)`，代入 x=2 → `12/4 = 3`，与洛必达一致。 |
