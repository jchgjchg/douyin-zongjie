## 一句话核心
Codex 不是只能写代码——把**记忆**（让它懂你/懂项目）、**技能**（把满意流程打包成可复用模板）、**站点**（一句话免服务器部署可访问网站）这三件套用起来，普通人也能零基础把"想法"落成"可交付的产品"。

## 内容拆解

### 1. 记忆：两种，自动 + 可控
- **持续记忆（关于你）**：Codex 在后台根据你和它对谈自动记录偏好/背景，无需操作；建议在设置里确认记忆开关已开，越用越懂你。
- **项目记忆（关于项目）**：项目文件夹内一个文件（输入 `/` 找"初始化/initialization"生成），Codex 据此自动带上整个项目上下文，且**不额外多吃 token**。作者以「计算机物语咖啡馆」文件夹示范，初始化后开任意对话都会自动携带项目全貌。

### 2. 技能 Skill：Codex 的"重复动作"引擎
- 内置一堆技能，重点演示**图像生成**：调用 GPT Image 2（当前最强生图模型之一），可生成/修改任意图片。
- 案例 1：给咖啡馆设计三款菜单，引用自家 logo 作风格参考 → 生成三种风格，且顺手用 **PDF 技能**直接产出三份可打印 PDF。
- 案例 2：修图做壁纸——拖入一张普通照片，说"改成艺术家拍的大片感"，无需 PS 即出片；延伸可做头像/海报/商品详情页。
- **自建技能（核心）**：当你把某流程打磨到满意，可 `@Skill Creator` 让它把流程打包成技能，以后 `@` 调用即按同一方式复现，不用每次重传参考图。
  - 演示：把"按 Excel 表格生成菜单图"打包成技能 → 改 Excel（冰沙→草莓冰沙、三明治→鸡蛋三明治、调价）→ 新窗口 `@` 技能重跑 → 出图自动同步最新内容、风格一致。

### 3. 站点 Site：一句话免服务器上线
- Codex 菜单栏单独给「站点」留位（作者称"王炸插件"）。`@Site` + "给我的咖啡店做个门户网站" → Codex 在自家服务器直接部署，**任何人可访问**，数据来自你文件夹的真实内容。
- 发布后默认需登录 ChatGPT 账号；到「站点」里点共享、访问权限设"所有人"、复制链接发给客户即可在手机/电脑查看。作者实测等了十多分钟部署完成。

### 4. Computer Use 插件：当下鸡肋
- 本想讲，实测多个场景未达预期、且几乎花光一周额度；作者判断**当前节点仍鸡肋**，但 Agent 演进快，几个月后或能真正操控电脑。收尾点题：**AI 时代最宝贵的是保持学习的心**。
