## 1. 一句话核心

新人起号别被"统一封面/养号玄学"框死——**新号要有"活人味"随便发、用 1 分钟极简或 5 分钟+有密度的内容跑通；涨粉后卡在 2000/8000/1 万三个"瓶颈期"时千万别断更，等算法验证完人群标签自然起量；几万粉后再统一封面分系列**。

## 2. 内容结构与要点

作者以"一年涨 60 万粉"的过来人身份，讲了一期"大概率没人说过"的新手起号经验（含 2026 下半年节点上的平台注意事项），想到哪说到哪，但信息密度高。

### 一、新号发视频时长：两个极端

- **一分钟以内**：用极端的話把一件事讲明白。
- **五分钟以上**：有条理、有逻辑、有信息密度地讲好一个故事。
- 强调"这不是平台要求"——平台最低门槛是**3 秒以上就能当视频发**，这是作者"近几个月大量测试"的结果。新人一般一天一条、慢慢涨粉。

### 二、涨粉后两条路：带货 vs 做 IP

- **带货**：随便拍，"以量决胜"——一个产品反复反复反复拍。
- **做 IP / 做内容**：好好打磨视频，想办法把**互动粉丝**提上来；不用特别多，**大概第二个月有 5000 有效粉丝就能进"伙伴计划"**，然后想办法变现；多参加"青创计划"等跟自己赛道/内容相关的平台活动，"能多参加今年都参加"，活跃才有更大未来。
- 伙伴计划门槛：作者说"一定要 5000 有效粉丝才能进"，要求"不违规、不涉及乱七八糟的东西、原创度够高"，基本都能签约。签约后建议**持续稳定更新、日更一条小爆款**——这是判断账号往哪推流、推多推少的重要节点。

### 三、三个"瓶颈期"（重点，作者最想讲的）

- 一般在 **2000、8000、1 万粉丝**左右各有一个瓶颈期：明明用心更新、文案比之前都好，但流量就是不如以前大。
- **这其实是好事**——粉丝固定了 = 你有铁粉了。
- 另一原因：**算法优化（验证人群）**。算法会把你的内容平等推给各类人 → 验证哪类人喜欢 → 继续推荐 → 再验证 → 再推荐，**总共约三次**；三次验证完才判定你账号标签是什么人喜欢。
- 应对：**一定一定一定不要断更**；瓶颈期别抠字眼找问题、别焦虑流量——不同赛道人群活跃时间不同，等算法找到确定喜欢你的人，就开始大量推、起量。"起量不是你视频更优秀了，是算法找到了人。"
- 作者提醒：瓶颈期分析数据、着急停更都没必要，**等瓶颈期过去数据才有参考价值**。

### 四、分系列的时机（"没人说过的一点"）

- 到了几万粉、视频多了容易乱，**一定要分系列：统一文字、统一封面**。
- 反常规观点：网上都让你开号就统一封面文字，作者认为**新账号太死板**——新号要有"活人味"、随便搁；**等有了固定粉丝群体、有喜欢你的人之后，再统一封面文字、分系列，事半功倍**。

### 五、常见问题快答

- **抄袭**：容易变成"空壳/搬运号"，东抄西抄割裂感严重，**最大问题是不涨粉**；抄一条火了也不是长久之计。
- **擦边**：作者说"其实没啥事，各行各业都在擦"——⚠️ 见下方可信度评估，此说法风险高，勿当操作建议。
- **连续几天没推荐页**：证明账号有东西违规了，一定是内容话题或思维出问题；整改后账号能正常发、会给推流，但**这段时间（推荐流量）不会给你**，搜索流量仍在（看每条视频文案带 # 话题的小蓝条、评论区也会出现，打好标签即可）。
- **新号注册三件套**：身份证 + 手机卡（注册用）+ 银行卡（提现用）。

## 3. 关键方法论 / 落地动作

| 阶段 | 动作 |
|---|---|
| 新号 | 1 分钟极简或 5 分钟+密度内容；有活人味、别急着统一封面 |
| 涨粉中 | 选带货（以量）或 IP（打磨+提互动）；冲 5000 有效粉进伙伴计划 |
| 瓶颈期 | 死守"不断更"；不在意流量、不抠数据；等算法验证完人群 |
| 几万粉 | 统一文字/封面、分系列，事半功倍 |
| 避坑 | 不抄袭（不涨粉）、擦边慎碰、违规整改后靠搜索流量续命 |
